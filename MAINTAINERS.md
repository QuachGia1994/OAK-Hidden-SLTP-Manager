# Maintainers and governance

OAK currently uses a maintainer-led governance model.

## Core maintainer

- [QuachGia1994](https://github.com/QuachGia1994): project direction, issue triage, pull request review, releases, security response, and Windows package verification.

## Decision process

- Bugs and security issues are prioritized by user impact and trading risk.
- Public behavior changes require tests and Vietnamese/English documentation.
- Trading-rule changes must state their invariant and preserve explicit user confirmation for real orders.
- Material changes are reviewed through pull requests; release notes record user-visible decisions.

Additional maintainers may be invited after sustained, high-quality contributions and demonstrated care for the project's security invariants.
