# Lỗi còn lại cần soi kỹ 🔴

## 1. Footer vẫn báo **MT5 Disconnected** dù Account card có dữ liệu

Trong ảnh Dashboard:

* Account card có server/account/balance/equity.
* Worker log có dòng kết nối MT5.
* Nhưng footer vẫn báo: **MT5 ● Disconnected**.

Đây là lỗi trạng thái. Có 2 khả năng:

### Khả năng A: heartbeat profile vẫn chưa đồng bộ hoàn toàn

Dù command đã truyền `--profile`, footer vẫn đọc từ SQLite heartbeat theo profile đang chọn. Nếu signal bot hoặc worker publish heartbeat dưới profile khác, footer sẽ đỏ.

### Khả năng B: app đang lấy Account từ nguồn khác, footer lấy từ heartbeat

Footer trong code đọc `mt5_state` từ heartbeat/state, rồi render Connected/Degraded/Disconnected.  Vì vậy nếu Account card có data nhưng heartbeat stale/missing thì footer vẫn đỏ.

**Cần sửa tiếp:** thêm diagnostics nhỏ hiển thị:

```text
Selected profile: VantageDemo
Heartbeat profile: VantageDemo
Heartbeat age: 2.1s
MT5 server from heartbeat: ...
Worker server: ...
```

Không có cái này thì lỗi trạng thái sẽ cứ như bóng ma trong nhà kho.

---

## 2. Telegram vẫn **Degraded (API unreachable)**

Footer hiện báo:

```text
Telegram ● Degraded (API unreachable)
```

Code status bar đang phân biệt rõ: configured, online, degraded. Nếu `tg_configured` có nhưng `tg_api_ok` false thì nó hiện degraded.

Điểm tốt: app không còn spam log.
Điểm chưa tốt: vẫn chưa biết lỗi là token/chat/network vì `telegram_client.py` có classify lỗi nhưng chưa thấy toàn bộ luồng cũ chuyển sang dùng helper này hết. `telegram_client.py` đã có phân loại `401 token_invalid`, `400 chat_not_found`, `502 bad_gateway`, `503 service_unavailable`, nhưng nếu UI không dùng error category để hiển thị thì người dùng vẫn chỉ thấy “API unreachable”.

**Nên nâng UI thành:**

```text
Telegram ● Token invalid
Telegram ● Chat ID invalid
Telegram ● API bad gateway
Telegram ● Network error
Telegram ● Online
```
