# Nhìn ảnh runtime: tốt hơn rõ ✅

## 1. Dashboard card có thêm stale info

Ảnh Dashboard hiện Account ghi:

```text
ICMarketsSC-MT5-6 | #7398029 (23s stale)
```

Cái này tốt hơn bản trước, vì app không còn “nói dối xanh lét” khi heartbeat đã cũ. Code hiện cũng render MT5 status theo age: Connected có giây, Degraded có stale, Disconnected có số giây ago.

## 2. Telegram status rõ hơn

Footer hiện:

```text
Telegram ● Degraded (Client error)
```

Tốt hơn `API unreachable` chung chung. Code đã map nhiều loại lỗi như `token_invalid`, `chat_not_found`, `bad_gateway`, `network_error`, rồi fallback thành Client error nếu là lỗi 4xx chưa phân loại.

## 3. Profile Running/Editing đã rõ

Ảnh Profile tab đang rất ổn:

```text
● Running: VantageDemo    ✎ Editing: ICMarkets
```

Cái này dễ hiểu hơn bản trước. List bên trái cũng phân biệt VantageDemo xanh và ICMarkets vàng, nhìn ra ngay đang chạy profile nào và đang edit profile nào.

## 4. Pending tab đã sạch

Ảnh Pending hiện bảng trống, log báo đã xoá tất cả lệnh hẹn giờ. Với commit `e79bed6`, phần `/del all` xoá cả lệnh hẹn giờ vào và đóng, nên đúng mục tiêu.

# 2 lỗi còn lại cần sửa 🔴

## 1. MT5 footer vẫn chuyển sang Disconnected khi heartbeat stale

Trong ảnh:

```text
MT5 ● Degraded (23s stale)
MT5 ● Disconnected (31s ago)
MT5 ● Disconnected (75s ago)
```

Trong khi Account card vẫn có server/account/balance/equity. Vậy vấn đề không phải MT5 hoàn toàn chết, mà là **heartbeat không được cập nhật đều**.

Khả năng cao:

* `MT5 Signal Bot` bị bận push dashboard/backfill/log nên heartbeat không publish đều.
* Hoặc heartbeat publish dưới profile khác.
* Hoặc GUI đang đọc heartbeat từ SQLite nhưng signal bot không update đủ nhanh.

**Cần fix tiếp:** heartbeat nên độc lập hơn. Đừng để signal loop chính kẹt là footer đỏ ngay. Gợi ý:

```text
- Tạo heartbeat thread riêng trong mt5_signal_bot.py, publish mỗi 2s.
- Nếu account card vẫn có data dưới 90s, footer nên là Degraded, chưa vội Disconnected.
- Thêm Diagnostics: selected_profile, heartbeat_profile, heartbeat_age, heartbeat_last_seen.
```

Hiện code đã hiển thị age tốt rồi, nhưng ngưỡng `>30s` thành Disconnected hơi gắt với app chạy nhiều process.

## 2. Telegram `Client error` chưa đủ rõ

`Client error` thường là lỗi HTTP 4xx không nằm trong map cụ thể. Nếu là token sai đáng ra phải `Token invalid`, chat sai đáng ra `Chat ID invalid`. Vậy có thể Telegram trả một dạng 400 khác, ví dụ parse mode Markdown lỗi hoặc payload không hợp lệ.

Cần log thêm:

```text
HTTP status code
Telegram response body
endpoint: getMe/sendMessage/polling
```

Không log token. Chỉ log kiểu:

```text
Telegram client_error: 400 Bad Request: can't parse entities
```

Nếu là Markdown parse lỗi thì sửa nhanh: gửi `parse_mode=None` hoặc escape Markdown.

# Logo phần Giới Thiệu bị lệch 🎯

Đúng, nhìn ảnh About thì logo đang **hơi lệch trái/không cân tâm với title**. Cụm content chính nằm giữa màn hình, nhưng logo icon có cảm giác “trôi” do frame/icon size hoặc pack/grid chưa căn theo cùng container.

## Cách sửa UI gọn nhất

Trong tab Giới Thiệu, nên đặt toàn bộ vào một `center_frame` cố định và dùng `grid` thay vì pack rải rác:

```python
center = ctk.CTkFrame(parent, fg_color="transparent")
center.place(relx=0.5, rely=0.18, anchor="n")

logo_label = ctk.CTkLabel(center, image=self.logo_image, text="")
logo_label.grid(row=0, column=0, pady=(0, 16))

title = ctk.CTkLabel(center, text="OAK Manager v3.15.0 Stable", font=("", 26, "bold"))
title.grid(row=1, column=0, pady=(0, 6))

subtitle = ctk.CTkLabel(center, text="Trading Operations Console for MT4 / MT5")
subtitle.grid(row=2, column=0, pady=(0, 12))
```

Nếu logo là emoji/text icon chứ không phải image, đặt width/height cố định:

```python
logo_box = ctk.CTkFrame(center, width=56, height=56)
logo_box.grid(row=0, column=0, pady=(0, 16))
logo_box.grid_propagate(False)
```

Rồi label icon:

```python
icon = ctk.CTkLabel(logo_box, text="🎛️", font=("", 30))
icon.place(relx=0.5, rely=0.5, anchor="center")
```

Như vậy icon luôn nằm đúng tâm, không bị lệch do font/emoji render.
